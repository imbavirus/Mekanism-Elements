# 3.0.8

## Fixes

### Adsorption Separator
- **Fixed Output Stalling**: Resolved an issue where the machine would not resume processing after the output tank was emptied until the block was replaced.
- **Fixed Block Breaking**: Machine now has correct hardness/resistance and drops properly when broken.
- **ComputerCraft**: Fixed `getChemicalInput` API annotation returning the wrong tank wrapper type.

### Radiation Irradiator
- **Fixed Stalling**: Resolved issues where the machine would not resume processing after the output tank was emptied, input tank was refilled, or energy was restored.
- **Fixed Block Breaking**: Machine now has correct hardness/resistance and drops properly when broken.

### Chemical Demolition Machine
- **Fixed Stalling**: Resolved issues where the machine would not resume processing after input was refilled, output slots were emptied, or energy was restored.

### Other Machines
- **Air Compressor & Seawater Pump**: Fixed block breaking behavior (mining speed and drops).
- **Recipes**: Fixed 40+ recipe parsing errors (Stonecutting, Evaporating, Rotary, Nucleosynthesizing) that were causing log spam and missing recipes.
- **Tags**: Fixed incorrect tag directory structure (`tags/blocks` -> `tags/block`) preventing custom blocks from being mineable.
