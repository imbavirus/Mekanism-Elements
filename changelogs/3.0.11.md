# 3.0.11

## Features

### Recipe Coverage
- **High-Quality Concrete**: Ported 18 missing colored clump recipes for High-Quality Concrete, ensuring full process parity for all variants.
- **New Recipes**: Added crafting recipes for `Syringe`, `Iodine Tablet`, and `Calcium Oxide Dust`.

### Translation & UI
- **Refined Translations**: Cleaned up various chemical names and fluid bucket labels (Helium, Nitric Acid, etc.).
- **JEI Stability**: Enabled strict `isIncomplete()` filtering in recipe types to prevent broken or empty recipes from appearing in JEI and machine interfaces.
