# 3.0.10

## Features

### Jetpack & Flight Improvements
- **Ammonia Jetpack Fuel**: The Jetpack and MekaSuit Jetpack Module now officially support Ammonia as a flight fuel! 
  - **Efficiency**: Ammonia burns 5x slower than Hydrogen, allowing for significantly longer flight times.
  - **Power**: Provides a 1.5x thrust multiplier for vertical movement.
- **Enhanced Hover Flight**: Significantly improved the horizontal movement mechanics for Ammonia-powered flight.
  - **Speed**: Horizontal flight speed is now doubled, allowing for much faster forward/backward movement while hovering.
  - **Braking**: Added responsive braking physics; releasing the movement keys now applies an active braking force to prevent drifting or "sliding on ice."

### Coolants & Chemicals
- **Helium Reactor Coolant**: Helium and Superheated Helium are now fully supported as reactor coolants.
  - **DataMap Integration**: Reinstated coolant functionality using Mekanism's newer DataMap system for 1.21.

## Fixes

### Internals & Compatibility
- **Creative Tab Support**: Added creative tab variants for filled Ammonia Jetpacks.
- **Mixin Stability**: 
  - Resolved a game crash caused by legacy coolant accessor Mixins.
  - Fixed a transformation error in the MekaSuit armor Mixin by properly handling interface default methods.
  - Improved player tick handling to prevent horizontal desync during flight.
