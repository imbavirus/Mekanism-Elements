# Mekanism: Elements
[![CurseForge](https://cf.way2muchnoise.eu/versions/1103224.svg)](https://www.curseforge.com/minecraft/mc-mods/mekanism-science)
[![CurseForge](https://cf.way2muchnoise.eu/1103224.svg)](https://www.curseforge.com/minecraft/mc-mods/mekanism-science)

An expansive addon for **Mekanism** that introduces a wide array of new chemical elements, advanced machinery, and flight overhauls. Dive deeper into scientific periodic tables with new processing chains and high-performance fuels.

> [!NOTE]
> This project is a fork of [Mekanism: Elements](https://github.com/fixdol/Mekanism-Elements) by [fixdol](https://github.com/fixdol).


## 🚀 Key Features

### ⛽ Advanced Jetpack Flight
Mekanism: Elements overhauls the flight experience with new fuel options and refined physics.
*   **Ammonia Fuel**: Use Liquid Ammonia as a high-efficiency alternative to Hydrogen.
    *   **5x More Efficient**: Significantly longer flight times compared to traditional fuels.
    *   **Vertical Boost**: 1.5x vertical thrust multiplier for faster climbing.
*   **Hover Overhaul**: Improved horizontal movement in hover mode (2.0x speed) with integrated **active braking**—stop instantly when you release the movement keys.

### ⚛️ Reactor Coolant System
Maximize your Fission Reactor's efficiency using the new Helium coolant cycle.
*   **Helium & Superheated Helium**: Fully supported as primary reactor coolants via Mekanism's DataMap system.
*   **Thermal Efficiency**: Designed for high-tier heat exchange and power generation.

### 🏭 New Machinery
*   **Adsorption Separator**: Extract specific substances from complex mixtures using high-performance adsorbents.
*   **Seawater Pump**: Automate the collection of Seawater directly from ocean biomes for use in chemical processing.
*   **Air Compressor**: Sump ambient air and compress it into gaseous form for industrial applications.
*   **Organic Liquid Extractor**: Extract vital biological compounds for advanced chemical synthesis.

### 🧪 Periodic Elements & Chemicals
A vast extension of the Mekanism chemical library:
*   **Noble Gases & Halogens**: Helium, Xenon, Bromine, Iodine.
*   **Nuclear Elements**: Americium, Californium, Curium, Strontium, Yttrium.
*   **Advanced Acids**: Nitric Acid, Aqua Regia, Netherite Acid.
*   **Building Tech**: **High-Quality Concrete** in 18 colors, including a complete processing chain from clumps to powders.

## 🛠️ Installation
1.  Ensure you have **NeoForge** installed.
2.  Install the latest version of **Mekanism**.
3.  Drop the `Mekanism-Elements` JAR into your `mods` folder.
